# Monarch Services — Complete Property Care

Official modern responsive web application for **Monarch Services**, Melbourne, VIC (Dandenong & Greater Melbourne Suburbs).

## 🌟 Overview & Core Pillars
- **Cleaning Services**: Residential & commercial cleaning, end-of-lease bond cleans, carpet steam cleaning, high-pressure washing.
- **Lawn Mowing & Garden Care**: Professional mowing, striping, edging, hedge trimming, pruning, weeding, and green waste removal.
- **Landscaping Services**: Turf laying, garden makeovers, mulching, paving, retaining walls, and outdoor styling.
- **Property Maintenance**: Handyman services, fence & gate repairs, gutter clearing, plaster repairs, and general trade fixes.

## 🚀 Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React + custom inline vector SVGs
- **Fonts**: Plus Jakarta Sans & Caveat

## 💻 Development
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build

# Preview build
npm run preview
```
